# Chef's Menu Manager

A React Native mobile app for managing a restaurant menu digitally.

## About

Created for Christoffel, an executive chef who needs a simple way to manage his restaurant menu. Built with React Native (Expo) and TypeScript.

## Features

- Add menu items with Dish Name, Description, Course, Price
- View all items in card layout
- Form validation with error messages
- Success alerts
- Empty state message
- Persistent storage

## Course Options

- Starter
- Main Course
- Dessert

## How to Run

1. `npm install`
2. `npx expo install react-dom react-native-web @expo/metro-runtime`
3. `npm start`
4. Press `w` to open in browser
